BSC with Agentic AI Tutorial · EP1-2

畫出來的圖，
能信到什麼程度

從一顆神經元的三視圖，到 20 顆的異常稽核——以及 AI 在過程中犯的四個錯。

這份文件是什麼：接續 EP1-1（判讀一個你打不開的檔案格式），把一次 Claude Code 協作從頭到尾拆解給你看。使用者只講了六句話，AI 犯了四個錯（其中一個是被自己推翻的結論）——全部保留在文件裡，沒有修飾。

適合誰讀：BSC（腦空間體中心）同仁，或任何要把 3D 影像資料「畫成圖給人看」的人。不需要會寫程式。

成果（一句話）：把 20 顆神經元畫成三視圖與圖版，並在最後用四個量化指標指出哪幾顆的影像不對勁——包括一顆疑似被另一條管線處理過的檔案。
