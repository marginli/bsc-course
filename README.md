# BSC with Agentic AI Tutorial — 線上課程

用 Agentic AI 做腦科學研究的線上課程。**不需要程式基礎。**
首頁講這門課是什麼、給誰看，並列出所有課程；點進一堂課有三個部分：

| 部分 | 內容 |
|---|---|
| 前置知識 | 沒有程式設計與腦科學背景也讀得懂的觀念、名詞速查與自我檢查 |
| 學習目標 | 學完這一集能做到的事 |
| 實作 | 教材本體，一個部分一頁（太長的部分再切成一節一頁）；每個動作下方有「做什麼／原理／自己寫／坑」的操作原理連結 |

另有一頁 **開始前你需要什麼**（`start.html`）：怎麼取得 Claude Code、要不要花錢、
什麼是終端機、第一次打開長什麼樣。

**https://marginli.github.io/bsc-course/**

## 關於這個 repo

裡面全部是產生器的產物（HTML / CSS），不是手寫的。內容的正本在本機的教材資料夾裡：
教材頁 `Tutorial/index.html`、前置知識與學習目標的 `.docx`，以及產生它們的 Python 程式。
網站由 `build_site.py` 組出來，實作頁由 `split_tutorial.py` 依原始教材頁的章節切開。
名詞速查連結、`M-xx` 交叉連結、五色圖例與閱讀時間都是建置時算出來的，不是手寫的。

文中所有位元組 offset、數值與統計皆為實際執行結果，未經修飾；
AI 在過程中犯的錯與事後被推翻的結論一併保留。

`robots.txt` 設為不索引——網址是公開的，但不希望被搜尋引擎收錄。
