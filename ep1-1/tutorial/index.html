判讀一個
你打不開的檔案格式

一次真實協作的完整重演：20 個打不開的 .am 檔，從「這是什麼」問到「這批資料其實分成兩群」。

這份文件是什麼：把一次 Claude Code 協作從頭到尾拆解給你看——使用者每一句指令、AI 每一步動作、AI 自己犯的錯與更正，全程可查證。

適合誰讀：BSC（腦空間體中心）同仁，或任何手上有「不知道怎麼開」的研究資料的人。不需要會寫程式。

成果（一句話）：判定出格式（AmiraMesh binary + zlib）、產出摘要表與過程報告，並在最後意外發現——那個被當成「純外觀差異」而統一掉的欄位順序，其實是兩條不同影像處理管線的指紋。
