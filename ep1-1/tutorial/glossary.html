約 3 分鐘

名詞速查表

看到不懂的詞先回來查。兩張表分別對應這個案例的兩個面向。

A. 檔案格式 / 影像資料

名詞白話解釋
檔頭 (header)檔案最前面一段「說明書」，記載這個檔裡裝的是什麼、多大、怎麼讀。這一集的主角。
magic number / magic string檔案開頭用來表明身分的固定位元組。看到它就知道是哪種格式，像是檔案的身分證。
AmiraMeshAmira / Avizo 這套 3D 影像軟體的原生格式（副檔名 .am）。本案 20 個檔就是這種。
體素 (voxel)3D 版的「像素」。本案每個體素代表 1 微米見方的空間。
zlib / deflate一種通用壓縮方式。AmiraMesh 的 HxZip 就是用它壓縮影像資料。
ushort16-bit 無號整數，每個體素佔 2 個位元組，理論值域 0–65535。注意：檔頭寫 ushort 不代表真的用滿——這一集的關鍵伏筆。
warp（對位）把每顆神經元的影像變形對齊到同一個「標準腦」座標系，這樣不同個體才能互相比較。

B. Claude Code / Agentic AI 工具

名詞白話解釋
Agentic AI「會自己動手」的 AI——不只回答問題，還能讀檔、寫檔、執行指令，完成多步驟任務。
Claude Code本案例用的 Agentic AI 工具。它能直接在你的電腦上讀寫檔案、跑程式。
十六進位傾印 (hex dump)把檔案的每個位元組用十六進位印出來看。判讀未知格式的基本手段，本案用 od 指令。
RFC網際網路的公開技術規格文件，有編號可查。本案引用 RFC 1950（zlib 格式規格）。
端到端驗證不只檢查「看起來對」，而是真的把整條路走完確認結果正確。本案是真的把資料解壓出來驗尺寸。
可逆 / 不可逆能不能還原。改寫原始資料是不可逆的，所以動手前要先備份。

C. 判讀與計算的基本名詞

端序 (endian)多位元組數字誰排前面的約定

幻覺 (hallucination)AI 猜測時語氣和知道時一樣自信

.py用 Python 寫的程式檔
